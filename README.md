# Circle In Minecraft: Bedrock
This project works by using command blocks to summon the cushions in a specific way. To start off, make sure you have a creative world with cheats on. Once you're in the world, open chat and do this commands: `/give @s command_block`. You should have a command block in your inventory now. Place it down and enter this command: `/execute at @p run summon cushion`. Change the sliders to "Always Active" and to "Repeating". Get out of the command blocks menu and cushions will start appearing under you. They should collide and if you run in a circle, make a shape that is circle-like. Still extremely laggy on low-end machines.
